# TOP E SHOP — ciemny motyw

Motyw kolorystyczny do strony B2B TOPESHOP (`https://b2b.topeshop.pl`).

Wtyczka do Chrome przyciemnia pulpit, katalog, kartę produktu, koszyk i zamówienia. Przyciski marki i zdjęcia produktów zostają bez zmian.

## Instalacja

1. Otwórz `chrome://extensions`.
2. Włącz tryb dewelopera.
3. Wybierz **Wczytaj rozpakowane** i wskaż ten folder.
4. Odśwież kartę sklepu.
